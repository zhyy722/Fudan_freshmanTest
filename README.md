# 复旦开学考试自动化工具（油猴脚本）

两个浏览器油猴脚本，安装 Tampermonkey 后导入即可使用，**不需要安装任何编程环境**。

| 脚本 | 作用 | 匹配网站 |
| --- | --- | --- |
| `fudan_quiz_bot.user.js` 多平台自动答题 | 按网站自动使用对应题库答题：识别题干、点选正确答案、自动翻页 | eLearning 测验、实验室安全考试系统 |
| `复旦实验室安全考前学习-自动挂机阅读.user.js` | 自动读完考前学习资料：自动打开未学习课件，倒计时结束后自动点“阅读完成” | 实验室安全考试系统（考前学习页） |

## ① 多平台自动答题

题库已内置（eLearning 入学教育 145 题 + 实验室安全 200 题），脚本会按网站自动切换，无需额外文件。

安装：油猴管理面板 → 工具/Utilities → 导入 → 选择 `fudan_quiz_bot.user.js` → 启用。

使用：登录网站进入测验/考试页 → 右下角面板点 **开始自动答题** → 自动作答、翻页，答完最后一题尝试交卷。

支持：单选/多选；选项名（A./A:）与文字分离；题干格式差异自动归一；题库中没有的题会跳过并提示，不会乱猜。

## ② 考前学习自动挂机阅读

详细说明见 [`使用说明.md`](./使用说明.md)。

安装方式同上，导入 `复旦实验室安全考前学习-自动挂机阅读.user.js`。

使用：打开实验室安全考试系统“考前学习”列表页，右下角面板自动开始；支持暂停/跳过/停止，全部读完自动停止，不会误点“学习完成”开始考试。

> 保持页面在前台，隐藏页面时浏览器会降低计时器速度。
